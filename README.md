# TWP Printing – Mockup Website

Mockup tampilan website TWP Printing (sablon kaos & merchandise custom) untuk persetujuan client.

## Halaman
- `index.html` – landing page (produk, cara order, paket event, galeri, testimoni, FAQ)
- `builder.html` – custom builder dengan preview 2D & 3D (Three.js)

## Menjalankan
Buka `index.html` langsung di browser. Preview 3D butuh koneksi internet (Three.js dimuat dari CDN).

## Catatan
Konten, harga, testimoni, alamat, dan nomor WhatsApp (`6281200000000` di `index.html` dan `assets/builder.js`) masih contoh.
